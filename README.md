# Lossless Image Optimizer

Convert your JPG, PNG, GIF, BMP, and TIFF images to the smallest possible WebP or AVIF files without losing any quality.

## What it does

- **Converts** your images to WebP and AVIF formats
- **Picks** the smallest file automatically
- **Guarantees** no quality loss (pixel-perfect validation)
- **Works** entirely in your browser (no uploads to servers)

## How to use

1. **Open** the website
2. **Drop** images or click to select them
3. **Wait** for conversion and validation
4. **Download** the optimized images

## Supported formats

**Input:** JPG, PNG, GIF, BMP, TIFF  
**Output:** WebP or AVIF (whichever is smaller)
